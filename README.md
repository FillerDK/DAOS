# DAOS – Databases and Operating Systems

SQL Server and Java exercises from the course *Databaser og OS* (Databases and Operating Systems) at Erhvervsakademi Aarhus (Datamatiker, autumn 2024).

| Folder | Topic |
|---|---|
| `L01` to `L05` | SQL exercises on creating tables, joins, aggregates and `GROUP BY`, subqueries and set operations, using the databases `eksempeldb`, `ordresystem`, `cykling` and `bankdb` |
| `L06` | Views (exercise 17) and queries on `bankdb` (exercises 18 and 19) |
| `L07` | `INSTEAD OF` triggers on `bankdb` (exercise 20) |
| `L08` | A view on the cycling database (exercise 14) |
| `L09` | Rental database script (`lejer`, `bil`, `udlejning`) |
| `Miniprojekt` | SQL for the mini project, including a trigger that stops a grade from being registered for an exam the student has already passed |
| `createSpg4.sql`, `insertSpg4.sql`, `selectSpg4.sql` | Practice question 4 with a film, director and actor database, using `UNION` and `FULL OUTER JOIN` |
| `JDBC2023` | Database access from Java with Java Database Connectivity (JDBC) |
| `L14 - Processer` | Lottery rows checked in parallel. The array of rows is split between threads, each a `Thread` subclass with a low and high index |
| `L15 - Traade` | Threads and synchronization. Exercises 9–12 and `dyrelyd`, including a `synchronized` method and a `volatile` field protecting a shared counter |
| `Aflevering DAOS Efteraar 2024 24V` | Hand-in with four versions (`ex1`–`ex4`) of a bakery simulation where people arrive at two entrances and a baker serves them, using threads that share one `Common` object |
